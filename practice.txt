GitHub — это веб-платформа для совместной разработки программного обеспечения, использующая систему контроля версий Git. 
Её используют разработчики, команды, компании и организации для хранения, обмена и управления кодом.

В будущем я могу использовать GitHub для хранения своих проектов, совместной работы над кодом и участия в открытых проектах.

GitHub Inc. была основана в 2008 году Томом Престон-Вернером, Крисом Ванстратом, Пи Джей Хайеттом и Скотом Чаконом. 
Сервис GitHub стал доступен публично в том же году.
